# Almacén Frontend

Frontend del sistema **Gestión de Almacén**, desarrollado con Angular y Angular Material.

Este proyecto corresponde a la interfaz web del sistema de almacén.  
Actualmente se encuentra en una etapa inicial de desarrollo y utiliza datos de demostración.

En esta etapa **no existe conexión con el backend ni con la base de datos**.

## Tecnologías utilizadas

- Angular 21
- Angular CLI 21.2.24
- Angular Material 21
- Node.js 24 LTS
- npm 11.19.0
- TypeScript
- HTML
- CSS

## Requisitos

Para ejecutar el proyecto es necesario tener instalado:

- Node.js 24 LTS
- npm
